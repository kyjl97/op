为什么必须开启 NAT？

如果不开启此项，连接主路由wifi的设备，只能访问国外网站，国内部分网站打不开，直播看不了，所有网站流量IP会判国外ip。

IP 动态伪装

原理剖析： 旁路由会对源地址进行一次伪装 (Masquerading)。外网看到的源地址是主路由的公网 IP，而不是设备的私网 IP。旁路由建立 NAT 表来追踪这些会话。

智能分流方案

进入 OpenWrt 后台：网络-DHCP/DNS-静态地址分配

OpenWrt 默认使用 DNSMASQ，我们可以利用 DHCP 选项为不同设备分配不同的网关。请根据你的需求选择以下一种方案：

方案一

大部分走代理，少部分直连

适合：全屋设备默认都要科学环境，只有电视、特定手机走国内直连。

MAC 绑定

给需要直连的设备添加标签 direct

DHCP 选项代码

// 强制direct标签网关为主路由
tag:direct,3,192.168.5.1
// 强制direct标签DNS为主路由
tag:direct,6,192.168.5.1
逻辑： 给特定设备打上 direct 标签。这些设备将强制使用 192.168.5.1 (主路由) 作为网关。
方案二

大部分直连，少部分科学上网

适合：保持原有网络体验，只有电脑、游戏机等特定设备走代理。

MAC 绑定

给需要走代理的设备添加标签 proxy

DHCP 选项代码

// 非proxy标签网关走主路由
tag:!proxy,3,192.168.5.1
// 非proxy标签DNS走主路由
tag:!proxy,6,192.168.5.1
逻辑反向： 如果设备标签不是 proxy，则网关和DNS分配为主路由 IP。只有打上 proxy 标签的设备才会走旁路由网关。
